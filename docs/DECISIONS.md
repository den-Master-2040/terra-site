## 2026-10-23 — Организация разработки

- Исходники в приватном GitHub-репозитории `terra-site`, ветка `main`.
- Сборка в GitHub Actions, готовый сайт публикуется в ветку `deploy` (принудительно, каждый раз с нуля).
- Домашний Ubuntu-сервер сам забирает `deploy` раз в минуту (systemd-таймер). Сервер ничего не принимает извне, на GitHub нет ключа от сервера; у сервера только deploy key на чтение.
- Веб-сервер — Caddy: готовый, сам получает HTTPS-сертификат. Адрес для показа — `dev.terra-electro.ru`. Заголовок `noindex`, короткий кэш.
- Боевой сайт потом переносится на нормальный сервер; домашний остаётся стендом.
- Картинки со старого сайта лежат в `static/img` и коммитятся в репозиторий (скачаны `tools/fetch-images.bat`).

## 2026-10-23 — Структура сайта

- Сайт не «с нуля по-новому», а со структурой старого terra-electro.ru: Главная, Каталог (Электродвигатели, СГП, Производители), Производство (Подстанции, КТПП, Низковольтное), Инжиниринг, Новости, О компании, Контакты.
- Лендинг с 3D — отдельная страница `landing.html`. Первый заход в сессии на главную перекидывает на лендинг (sessionStorage); внутри сайта не перекидывает. Кнопка «Двигатель в 3D» в верхней строке.
- Светлая тема основная, тёмная по кнопке, выбор запоминается (localStorage).
- Категории без своей страницы открывают форму заявки с подставленной темой (`?topic=`).
- Тексты взяты со старого сайта и слегка отредактированы; все хранятся в `content.py`.
